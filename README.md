# 快速完成编写一千万行代码的成就

本项目实现了一个用于判断奇偶数的脚本。不过，我们不使用取模这种奇技淫巧，而是一个数一个数地进行匹配。借助代码生成器，这可以轻松达到数千万行的代码量。

## 代码生成

```sh
# 想要多少行自己填，这里是一千万行
node codegen.js 10000000
```

## 运行程序

```sh
node output.js
```

## 统计代码量

运行

```sh
tokei --no-ignore
```

结果如下

```txt

===============================================================================

 Markdown                1           37            0           27           10

```
